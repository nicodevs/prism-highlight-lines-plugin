Prism Highlight Lines Plugin

A plugin for highlighting code lines with annotations in comments.

add - Green
remove - Red
highlight - Yellow

Annotation Syntax:

  • [tl! add] - Mark line as added (green)
  • [tl! remove] - Mark line as removed (red)
  • [tl! highlight] - Highlight line (yellow)
  • [tl! add:3] - Add next 3 lines (including current)
  • [tl! remove:-2,3] - Remove 3 lines starting 2 lines up
  • [tl! highlight add:1 remove:-1] - Combine multiple annotations

Example 1: Basic Add

interface UserConfig {
  name: string; // [tl! add]
  email: string;
  legacyId?: number;
}

Result:

interface UserConfig {
  name: string; // [tl! add]
  email: string;
  legacyId?: number;
}

Example 7: Combo - All Three Types

class PaymentProcessor {
  async processPayment(amount: number): Promise<PaymentResult> {
    // Old synchronous validation
    if (amount <= 0) throw new Error('Invalid amount'); // [tl! remove]

    // New async validation with detailed checks // [tl! add:3]
    const validation = await this.validateAmount(amount);
    if (!validation.isValid) throw new PaymentError(validation.message);

    const result = await this.gateway.charge(amount); // [tl! highlight]

    return result;
  }
}
